# HWpilot项目设计文档

**综述：本项目是面向程设课程的课程助手，目的是帮助用户管理程设作业、引导用户建立初步的版本控制思想并帮助用户学习程设课程的难点。另外，为了完成某些特定功能，我们计划在项目中引入Deepseek的API。**

## 功能1：对作业进行版本控制

- 我们调用原生的git，将程设课程的不同作业理解成不同的分支（main分支本质上不继续发展），每次作业的不同版本理解成在这个分支上commit

- 用户可以选择将某次作业的某个文件更改成另外某个版本的文件（类比git checkout）

## 功能2：帮助用户完善作业

- 用户需要在新建某个作业项目的时候提交该作业的所有作业要求，此时可以点击**启发式学习**按钮，ai会返回关于这次作业的一些启发式问题，引导用户更好地开始这次作业。

- 每当用户完成了某部分作业，可以点击**作业批改**按钮，ai会返回用户作业中存在的问题并给出修改建议。这时我们会将此次对话的内容总结后纳入ai交互库，用于生成总结报告。

- 当用户觉得一份作业完成得差不多，可以选择进行**提交**，此时会在作业分支树上新增一个节点。

## 功能3：生成总结报告

- 基于之前的ai交互库，用户可以选择在每一次作业以及期末完成了所有作业之后点击**生成复习建议**按钮，ai会根据之前的对话总结错题、给出相似练习题。

- 用户还可以通过提交课程ppt来帮助ai总结复习建议和报告。

## 功能4：（有额外时间的附加功能）

- 上面所说的都是作业模式，我们希望平行地设置一个学习模式，可以通过与ai多轮对话来详细地理解某个知识点。

- 比如关于虚函数这个知识点，用户可以提出多个想法，并提交课程ppt，ai会根据用户的想法给出相应的解答和提醒，也会纳入上述功能3的期末复习总结之中。
