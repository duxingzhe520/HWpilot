### 一、multiset
- 定义
```cpp
template<class key, class pred = less<key>, class A = allocator<key>>
// 只重载 < 
class multiset{};

template<class T>
struct less : public binary_function<T, T, bool> {
	bool operator() (const T& x, const T& y) {
		return x < y;
	}
}
```
- 成员函数
```cpp
iterator find(const T& val);
iterator insert(const T& val);
void insert(iterator first, iterator last);
int count(const T& val);
iterator lower_bound(const T& val); // 查找最大位置it，使得[begin(), it)所有元素都比val小，即返回第一个>=val的迭代器
iterator upper_bound(const T& val); // 返回第一个 > k的迭代器
pair<iterator, iterator> equal_range(const T& val);
```

### 三、STL中的算法
- 不变序列算法
```cpp
template<class Init, class Func>
Func for_each(Init first, Init last, Func f);
size_t count(Init first, Init last, const T& val);

template<class T>
T min_element(T first, T last); // 最小指没有元素比它小，而不是它比别的不同元素都小
```
- 变值算法
```cpp
template<class Init, class Outit, class Unop>
Outit transform(Init first, Init last, Outit x, Unop uop); // 对区间内每个数执行uop(*i)，返回迭代器x + (last - first)
```
