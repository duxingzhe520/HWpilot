### 一、STL(Standard Template Library)的基本概念
#### 容器：容纳各种数据类型的数据结构，是类模板
- 顺序容器，序列容器
	- vector, deque, list
	- vector随机存取任何元素在常数时间完成，尾端增删元素性能较佳
	- deque双良队列，随机存取任何元素在常数时间完成，首尾增删元素具有较佳性能
	- list双向链表，不支持随机存取，在任何位置增删元素在常数时间内完成
- 关联容器，有序容器
	- set, multiset, map, multimap
	- 插入元素按相应排序规则确定位置
	- 插入和检索的时间是$O(\log N)$
- 容器适配器
	- stack, queue, priority_queue
	- stack栈，序列中被删除、检索、修改的项只能是最近插入序列的项（栈顶的项）
	- queue队列，先进先出
	- priority_queue优先级队列，最高优先级元素总是第一个出列

- 标准库容器共有的成员函数
	- 比较运算符（按字典序比较）
	- empty, max_size, size, swap
- 只在第一类容器中的成员函数
	- begin, end, rbegin, rend, erase, clear
- 顺序容器的成员函数
	- front, back, push_back, pop_back, erase

#### 迭代器
- 用于指向第一类容器中的元素，用法和指针类似
```cpp
vector<int> v;
v.push_back(1); v.push_back(2);

vector<int>::const_interator i;
for (i = v.begin(); i != v.end(); i++) {
	cout << *i << endl;
}

vector<int>::reverse_iterator r;
for (r = v.rbegin(); r != v.rend(); r++) {
	cout << *r << endl;
}

vector<int>::iterator j; // 可以通过*j修改内容
j = v.begin();
while (j < v.end()) {
	cout << *j << endl;
	j += 2;
}
```
- 输入 、输出、正向、双向、随机访问，后面的迭代器拥有前面迭代器的所有功能

#### 算法简介
- 是一个个的函数模版，大多定义在``<algorithm>``中
- copy, remove, fill, replace, ... 

#### STL中的大小比较
- 以下三个说法等价
	- x 比 y 小
	- x < y为真
	- y 比 x 大
- x 与 y 相等 等价于 x < y和 y < x 同时为假

### 二、函数对象

- 一个类重载了()为成员函数，则该类为函数对象类，该类的对象为函数对象
```cpp
template<class InIt, class T, class Pred>
T accumulate(InIt first, InIt last, T val, Pred pr);

accumulate(v.begin(), v.end(), 0, Sum);
```
```cpp
list<int> lst;
lst.sort(greater<int>()); // 这里greater<int>是一个函数对象类，用一个()将其实例化，变成一个函数对象
```
其中，pr可以是函数指针或者函数对象
- 使用函数对象的好处是它可以拥有一些超参数（类中的属性）
- 用sort进行排序
```cpp
sort(a, b, compare); // 其中a是起点（迭代器），b是终点（迭代器），compare是排序规则结构体名
struct compare {
	bool operator () (const T& a1, const T& a2) {
		return ...;
	}
};
```
