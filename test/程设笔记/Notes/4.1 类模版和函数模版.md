### 一、函数模版
- 问题：对不同的对象想要进行同名的操作
	- 函数重载的办法
```C++
sort(class A){};
sort(class B){};
```
- 可以定义一次抽象的类，然后定义一个函数模版
```C++
template<class T>
void print(const T array[], int size) {
	int i;
	for (int i = 0; i < size; ++i) {
		std::cout << array[i];
		// 注意要事先对 << 有合适的重载
	}
	return;
}
```
- 由模版调用时转化为的函数，称为模版函数
- 一个函数模版也可以有多个类型参数
	- 可以用类型参数说明，也可以用基本数据类型说明
	- 也可以用来声明函数内部的局部变量
- 赋值兼容引起参数二义性
```C++
template<class T>
T myFunction1(T arg1, T arg2) {
	return arg1;
}
myFuntion1(5, 8.4); //error: 二义性！
myFuntion1<double>(5, 8.4); //编译通过，显示地指定参数类型！

template<class T1, class T2>
T1 myFunction2(T1 arg1, T2 arg2) {
	return arg1;
}
myFunction2(5, 8.4); //编译通过！
```
- 要与函数模版形成重载，同一函数名只能参数数量不同
- 函数和模版的匹配顺序
	- 先找参数完全匹配的函数
	- 再找参数完全匹配的模版
	- 在没有二义性的前提下，找参数经过自动转换后能够匹配的函数
	- 报错

### 二、类模版
##### 泛型程序设计
- 算法实现时不指定具体要操作的数据的类型
- 减少代码的重复编写

##### 类模版的声明
```cpp
template <class T>
class Array {
	T* ptrElement;
	int size;
public:
	Array(int length) : size(length) {};
	~Array() = default;
	int len() { return size; }
	T getElement(int index) {
		return *(ptrElement + index);
	}
};
```

- 类模版在后续声明时，必须带上抽象类列表，且在类外实现时，需要重新写一遍template的声明
```cpp
template<class T1, class T2>
class Pair {
public:
	T1 key;
	T2 value;
	Pair(T1 k, T2 v) : key(k), value(v) {};
	bool operator < (const Pair<T1, T2>& p) const;
};

template<class T1, class T2> // 不可省略
bool Pair<T1, T2>::operator < (const Pair<T1, T2>& p) const {
	return key < p.key;
}

Pair<string, int> student("Tom", 19); // 必须指明抽象的参数列表具体的类型
```
- 模板类 = 实例化的类模版
- 同一个类模版的两个模板类不兼容
```cpp
Pair<string, int>* p;
Pair<string, double> a;
p = &a; // Error!
```
- 类模板的类型参数表可以包括非类型参数，但这不代表类Array里有成员size
```cpp
template<class T, int size>
class Array {
	T array[size];
public:
	void print() {
		for (int i = 0; i < size; ++i) {
			std::cout << array[i] << std::endl;
		}
	}
};

Array<double, 40> a; // 必须指定size！
```

##### 类模板的继承
- ==类模板==从==类模版==派生
```cpp
template<class T1, class T2>
class A {
	T1 v1; T2 v2;
};

template<class T1, class T2>
class B : public A<T2, T1> {
	T1 v3; T2 v4;
}

template<class T>
class C : public B<T, T> {
	T v5;
}
```

- ==类模版==从==模板类==派生
```cpp
template<class T1, class T2>
class A {
	T1 v1; T2 v2;
};

template<class T>
class C : public A<int, double> {
	T v5;
}
```

- ==类模板==从==普通类==派生
```cpp
class A {
	int val;
};

template<class T>
class C : public A {
	T v;
}
```

- ==普通类==从==模板类==派生
```cpp
template<class T>
class A {
	T v;
};

class C : public A<int> {
	int v;
}
```

##### 类模板的友元
- 函数/类/类的成员函数作为类模板的友元
```cpp
template<class T>
class tmp {
	friend void Func();
	friend class A;
	friend void B::Func();
	// 任何从tmp实例化来的类都有以上三个友元
};
```

- 函数模版作为类模版的友元
```cpp
template<class T1, class T2>
class Pair {
	template<class T3, class T4>
	friend ostream& operator << (ostream& o, const Pair<T3, T4>& p);
};
```

- 函数模版作为类的友元（与上同理）

- 类模版作为类模版的友元
```cpp
template<class T>
class A {
	void Func(const T& p) { std::cout << p.v; };
};

template<class T>
class B {
	T v;
public :
	template<class T2>
	friend class A;
};

B<int> b(5);
A<B<int>> a;
```

##### static成员
- 类模版中可以定义静态成员，则从该类模板实例化出的所有类都包含同样的静态成员
```cpp
template<class T>
class A {
	static int count;
};

template<T> int A<T>::count = 0; // 共享初始化

// 特化不同模板类的初始化
template<> int A<int>::count = 0;
template<> int A<double>::count = 1;
```

### 三、string类

- string类是一个模板类
```cpp
typedef basic_string<char> string;
```

- 初始化
```cpp
string s1("hello"); 
string s2(8, 'x'); // 8个'x'的字符串
string s3 = "March";

string e1 = 'c'; // Error！
string e2(8); // Error！

s1 = 'n'; // 这是符合要求的
```

- 逐个访问string对象的字符
```cpp
string s1("hello");
s1.at(0); //会做下标范围检查
```

- 子串
```cpp
string s1("hello world"), s2;
s2 = s1.substr(4, 5); // 从下标4开始共5个字符
```

- 交换
```cpp
string s1, s2;
s1.swap(s2);
```

- 字符串流处理
```cpp
#include <sstream>
string input("hello 1 2 3");
istringstream inputString(input);
string string1;
int a, b, c;
inputString >> string1 >> a >> b >> c;
```
